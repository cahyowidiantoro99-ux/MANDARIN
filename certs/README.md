Public database CA downloaded from the certificate link in the authenticated Supabase project dashboard, Database Settings > SSL configuration.

Source: https://supabase-downloads.s3-ap-southeast-1.amazonaws.com/prod/ssl/prod-ca-2021.crt

Used only by the PostgreSQL TLS client when PG_SSL_CA_FILE is set. Certificate and hostname verification remain enabled. This is a public CA certificate, not a private key or API credential.
